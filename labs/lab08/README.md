# Lab 8: Topic Modeling (LSA & LDA) на вакансіях DOU

1. **Підзадача:** Unsupervised clustering текстів вакансій для виявлення "сюжетів" (ролей, вимог).
2. **Дані:** Відфільтровані речення з вакансій (тільки $\ge 4$ слів).
3. **Моделі:** Перевірено LSA та LDA для $k=5$ та $k=8$. 
4. **Головний інсайт:** Датасет вакансій є двомовним (англійські хард-скіли + український опис). Це створює "сміттєві" теми зі стоп-слів (потрібна кастомна фільтрація обох мов). LDA показала себе краще для коротких речень, формуючи цілісні "ролі", тоді як LSA розпалася на словникові теги.
5. **Наступні кроки:** Додати масив українських стоп-слів, знизити `max_df` до 0.6 та використати лематизацію (lemma_text).
