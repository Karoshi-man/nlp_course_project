# Lab 9: Word Embeddings (Word2Vec / FastText) на корпусі DOU

1. **Який корпус використано:** Корпус ІТ-вакансій DOU (поле `clean_text`). Після відкидання текстів, коротших за 15 слів, робочий набір склав 583 документи (~265,416 токенів). Слова залишено у вихідній формі (без лематизації) для збереження автентичного ІТ-сленгу.
2. **Які моделі натреновано:** Word2Vec та FastText (з використанням бібліотеки Gensim).
3. **Які параметри використано:** Обидві моделі тренувалися з однаковими налаштуваннями для чесного порівняння: `vector_size=100`, `window=5`, `min_count=3`, `sg=1`. Вибір Skip-gram (`sg=1`) зумовлений тим, що він краще моделює контекст для рідкісних доменних слів (назв фреймворків).
4. **Які типи слів аналізували:** Часті загальні слова (`досвід`, `команда`), доменні/рідкісні ІТ-терміни (`kubernetes`, `backend`, `sql`), слова з морфологічною варіативністю (`розробник`, `розробника`), та слова з транслітом/помилками (`сіньйор`, `javascipt`).
5. **Які 5 кейсів виявились найцікавішими:**
   * `agile` (Корисно) — моделі ідеально відтворили контекст soft-skills (`mentoring`, `collaborative`).
   * `docker` (Корисно) — FastText знайшов DevOps-стек (`CI`, `Kubernetes`) попри приклеєну пунктуацію.
   * `sql` (Некорисно) — FastText згенерував лексичні "галюцинації" (`Бронювання`, `звання`) на невідомій короткій абревіатурі.
   * `команда` (Некорисно) — моделі вивчили синтаксис (сусідні слова в реченні, як-от `яка`, `надає`) замість семантичних синонімів (`колектив`).
   * `backend` (Змішаний) — Word2Vec знайшов семантичну пару (`frontend`), а FastText виступив лексичним збирачем (`back-end`, `(backend`).
6. **Де FastText був кращий / де ні:** * **Кращий:** При роботі з "брудним" текстом (трансліт, дужки, приклеєні коми). Завдяки n-грамам він легко дістає технології навіть з неохайного написання. 
   * **Гірший:** На абревіатурах, яких немає у словнику. Замість того, щоб видати помилку (як це робить Word2Vec), він шукає випадкові слова з подібними літерами, руйнуючи семантику.
7. **Чи embeddings реально корисні для вашого корпусу:** Так. Вони довели здатність розрізняти контекст soft-skills та утворювати кластери hard-skills. Проте, експеримент показав, що для максимальної користі корпус вимагає більш агресивного попереднього очищення (видалення приклеєної пунктуації регулярними виразами) — інакше моделі витрачають ресурс на моделювання синтаксису та помилок, а не чистої семантики.
