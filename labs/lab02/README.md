# Lab 2: Deterministic Cleaning & Normalization

## Огляд
Мета цієї лабораторної роботи — розробити надійний, відтворюваний (детермінований) пайплайн для підготовки тексту вакансій до етапу витягування навичок (Skill Extraction). Використання LLM або недетермінованих моделей на цьому етапі суворо заборонено.

## Архітектура пайплайну (`src/preprocess.py`)
Пайплайн побудовано у вигляді модульного конвеєра з використанням класу конфігурації `PreprocessPolicy`:
1. **Normalization:** Уніфікація типографіки (апострофи, лапки, тире), виправлення битого кодування через `ftfy`, згортання пробілів.
2. **PII Masking:** Маскування електронних пошт, посилань та номерів телефонів (Regex).
3. **Domain Cleaning:** Специфічне видалення веб-сміття з сайту DOU (шаблонні кнопки соцмереж).
4. **Smart Sentence Splitter:** Кастомний алгоритм розбиття на речення. На відміну від стандартних рішень, він "заморожує" ІТ-терміни з крапками (`Node.js`, `.NET`, `C++`, версії `14.1.2`) та стандартні українські скорочення (`м.`, `вул.`) перед розбиттям, зберігаючи їхню цілісність.

## Тестування (Mini-regression)
У зошиті `lab2_cleaning_normalization.ipynb` реалізовано автоматичне тестування на базі 20 специфічних граничних випадків (`tests/edge_cases.jsonl`). 
Пайплайн успішно проходить перевірки на:
* **Ідемпотентність:** `preprocess(preprocess(x)) == preprocess(x)`
* **Відсутність порожніх вибухів:** текст не зникає після обробки.
