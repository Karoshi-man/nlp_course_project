**Інструмент:** Stanza (uk)

## Що зроблено
1. Написано скрипт `src/ling_features.py` для генерації лем та POS-тегів.

3. Проведено Error Analysis (виявлено проблему руйнування складних токенів типу C++ та Node.js).

## Основні метрики на Gold Subset
* **Precision (Raw Text):** 100% (5/5)
* **Precision (Lemma Text):** 20% (1/5)

## Висновок
Для задачі витягування іменованих сутностей з ІТ-вакансій лематизація знижує якість, руйнуючи цілісність технологій та ламаючи контекстні патерни. У подальшому пайплайні леми будуть застосовуватись лише для задач пошуку/дедуплікації, але не для NER.
