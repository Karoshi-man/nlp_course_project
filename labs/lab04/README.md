# Лабораторна робота 4: Rule-based Information Extraction

## 1. Які 3 типи полів ви витягуєте
* **SALARY**: Зарплатні вилки та фіксовані суми (USD/UAH).
* **EXPERIENCE_YEARS**: Мінімальні вимоги до років комерційного досвіду.
* **ENGLISH_LEVEL**: Рівень володіння англійською мовою за шкалою CEFR.

## 2. Які правила/словники використали
* Створено словник мапінгу (`resources/english_levels.json`) для зведення синонімів (Fluent, Upper-Intermediate) до єдиного стандарту CEFR (C1, B2).
* Використано Regex із негативним lookbehind (`(?<!\d)`) для точного витягування грошових сум та уникнення парсингу частин інших великих чисел.
* Застосовано Regex із word boundaries (`\b`) для ізольованого пошуку рівня англійської, щоб відсікати хибні спрацювання (наприклад, "B2B").
* Впроваджено евристичні фільтри (досвід < 15 років, зарплата > 200), щоб відсіяти вік кандидатів або версії технологій.

## 3. Precision по кожному типу поля
*(Оцінка проводилась на розміченому Gold Subset з 10 вакансій)*

| Поле | Precision |
| :--- | :---: |
| **SALARY** | 1.00 |
| **EXPERIENCE_YEARS** | 1.00 |
| **ENGLISH_LEVEL** | 1.00 |

## 4. Топ-5 edge cases у нашому корпусі
1. **"B2B продажі"**: Regex міг сприйняти "B2B" як рівень англійської B2. Вирішено через межі слів `\b`.
2. **"Від 18 років"**: Алгоритм міг прийняти віковий ценз за досвід роботи. Вирішено через обмеження `exp_val <= 15`.
3. **Зарплата у форматі "k"**: Фрази типу "від 2k до 4k$". Вирішено функцією нормалізації, яка множить значення на 1000.
4. **Дробовий досвід**: "1.5 роки" або "півтора року". Вирішено підтримкою `float` у регулярному виразі.
5. **Лише одна межа зарплати**: "up to $5000". Вирішено встановленням мінімуму в 0.
