# Лабораторна робота 6: TF-IDF + Logistic baseline

**1. Напрям проєкту:** Напрям **В (Extraction / NER)**. Мета — вилучення іменованих сутностей (технічних навичок) з ІТ-вакансій платформи DOU.

**2. Classification-підзадача:** Оскільки основна задача — NER, для цієї лабораторної було сформульовано допоміжну підзадачу: **бінарна класифікація речень**. 
* **Клас 1:** Речення містить технічні навички / технології.
* **Клас 0:** Речення містить загальний опис компанії, обов'язки без прив'язки до стеку або умови праці.
Це працюватиме як фільтр перед етапом NER, щоб відкидати неінформативний текст.

**3. Порівняння baseline-варіантів:**
Було побудовано та порівняно 2 sklearn-пайплайни (TF-IDF біграми + Logistic Regression):
* **Baseline 1:** Стандартна логістична регресія.
* **Baseline 2:** Логістична регресія з балансуванням класів (`class_weight='balanced'`), щоб компенсувати сильний дисбаланс (77% на 23%).

**4. Основні цифри (на Test Set):**
* **Baseline 1:** Accuracy = 0.9270 | Macro-F1 = 0.8849
* **Baseline 2 (Найкращий):** Accuracy = 0.9599 | **Macro-F1 = 0.9441**

**5. Результати Error Analysis та наступні кроки:**
Аналіз 15 помилок (False Positives та False Negatives) показав:
* Модель часто "розумніша" за нашу базову Regex-розмітку: вона успішно знаходить нові технології (наприклад, *LangChain, NoSQL*), які не були в словнику. Це класична проблема **Noisy Labels**.
* Присутній **Context Overlap**, коли в одному реченні змішані і технології, і загальні умови роботи компанії.
* **Що фіксити далі:** Класифікація цілих речень є занадто грубим інструментом. У наступних лабораторних роботах ми перейдемо до точкового вилучення сутностей (NER / Sequence Labeling), що дозволить вирішити проблему змішаного контенту.
