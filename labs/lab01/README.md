# Lab 1: Data Collection & Audit

## Огляд
Перший етап проєкту був присвячений формуванню корпусу текстів вакансій та проведенню глибокого аналізу даних. Основна увага приділялася розумінню структури вакансій на DOU та виявленню потенційних проблем для автоматичної обробки.

## Виконана робота
- **Збір даних:** Сформовано датасет із понад 500 вакансій за допомогою скрейпінгу сторінок DOU.
- **Базова очистка:** Видалено HTML-теги та артефакти розмітки, отримано чистий текст описів.
- **Аудит даних:**
    - Проаналізовано частотність слів та розподіл довжини описів.
    - Виявлено значну кількість PII (пошти, телефони) та веб-сміття, що потребують маскування.
    - Ідентифіковано складні випадки для токенізації (технології з крапками та спецсимволами: .NET, C++, Node.js).
- **Документація:** Створено `dataset_card.md` з результатами аудиту та `labeling_guidelines.md` для майбутньої розмітки сутностей.
